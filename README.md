# Avaliação Final — Big Data | TechPay

**Disciplina:** Big Data  
**Alunos:** Gabriel Ramos e Thales Vieira  

Este repositório reúne os códigos, análises e evidências desenvolvidos para a avaliação final da disciplina de Big Data.

O trabalho utiliza uma base fictícia da fintech **TechPay**, composta por **30.000 transações realizadas ao longo de 2025**, com informações sobre clientes, valores, canais de atendimento, categorias de estabelecimento, scores de risco e crédito e identificação de possíveis fraudes.

A proposta foi desenvolver um fluxo de dados partindo da arquitetura e organização das informações até a geração de análises para apoio à tomada de decisão.

## Estrutura do trabalho

O projeto foi organizado nas seguintes etapas:

- **Etapa 1 — Arquitetura Big Data:** definição do fluxo dos dados, tecnologias, formatos e estratégia de particionamento;
- **Etapa 2 — Pipeline Big Data:** ingestão e transformação dos dados nas camadas Raw, Bronze, Silver e Gold;
- **Etapa 3 — Análise e Dashboard:** exploração dos dados e construção de indicadores relacionados principalmente ao risco e à ocorrência de fraudes;
- **Etapa 4 — Machine Learning:** aplicação adicional de um modelo de Regressão Logística para classificação de transações fraudulentas.

A implementação foi realizada principalmente com **Python, PySpark, Pandas, DuckDB e Plotly**, buscando manter uma relação direta entre a arquitetura proposta e as etapas executadas.

Cada pasta contém os respectivos códigos e arquivos explicativos utilizados no desenvolvimento da avaliação.
